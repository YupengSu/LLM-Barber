Method

LLM-Barber starts from any pruned model and rebuilds the mask of every Self-Attention and MLP block in one pass. The weights keep their values and the sparsity stays the same.

1

Measure the error at the block

Layer-wise pruners fit each projection to its own output, ‖WX − (W ⊙ M)X‖², and the small biases add up from layer to layer. LLM-Barber takes one error at the output of the whole block, so the masks of all its projections are judged together:

E=‖Block(W,X)−Block(W⊙M,X)‖22
2

Score every weight with its gradient

At the dense model E is zero and its gradient vanishes, which is why methods such as SparseGPT turn to the Hessian. After pruning E is no longer zero, so the first-order term is enough. Pruning or regrowing a weight changes it by |ΔWij| = |Wij|, which gives the score:

ΔE≈∂E∂W·ΔW ⇒Sij=|Wij|·|∂E∂Wij|
3

Swap weights in pairs

Pruned weights are sorted by S from high to low and kept weights from low to high, then paired in order. Each swap regrows one weight and prunes another, so the sparsity never changes. Only a fraction α of the pairs with a positive gain is swapped:

N=α·|{i:Sigrow−Siprune>0}|

Pairs are formed within a group: an output row, an input column, a matrix or the whole block. The best α sits where the outlier pairs end, about 10% after Magnitude and 1% after Wanda on LLaMA-7B.

One pass

One pass beats iterative regrowth

DSnoT also rebuilds masks without training, but prunes and regrows weights over many cycles with a fixed iteration limit, layer by layer. LLM-Barber rebuilds each block once and recovers far more from a poor start.

Zero-shot

Accuracy follows the perplexity

Mean accuracy over BoolQ, RTE, HellaSwag, ARC-e, ARC-c and OpenBookQA. From a magnitude mask, LLaMA3-8B goes from 36.57 to 52.58; the dense model has 62.79.

Code

The repository rebuilds masks from Magnitude, SparseGPT or Wanda on LLaMA and OPT models, and has the scripts for every experiment in the paper.

Set up
conda create -n barber python=3.10
conda activate barber
pip3 install torch torchvision torchaudio
pip3 install -r requirements.txt
Rebuild a Wanda mask on LLaMA-7B
python main.py --model huggyllama/llama-7b \
  --prune_method wanda \
  --sparsity_ratio 0.5 --sparsity_type unstructured \
  --prune_barber --prune_granularity output1 --threshold 0.01 \
  --save_ppl out/ppl

--threshold is the swap ratio α (the paper's mask rebuilding ratio). Commands for every experiment are in script/.
